# Official CI logo artwork

Conservation International's identity guidelines (1.2, 1.13) do not allow the
logo to be redrawn, so only officially supplied files go here.

| File | Status | Use |
|---|---|---|
| `ci-symbol.png` | ✅ present | The symbol (blue circle + green bar), shown beside the app name |
| `ci-logo-color.svg` / `.png` | optional | Full lockup, gray wordmark — light backgrounds |
| `ci-logo-white.svg` / `.png` | optional | Full lockup, white wordmark — dark backgrounds (1.14) |

If the full lockups are added, the app switches to them automatically.
Guideline 1.1 asks for the symbol and wordmark to appear together, so the
official lockup (ideally the Cambodia office version, 2.1) is preferred when available.
